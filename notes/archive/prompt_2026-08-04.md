## Standing rules

- **Never** add a `Co-Authored-By: Claude` trailer to a commit.
- **Look at what you produce.** This project has shipped a screenshot that was
  actually QEMU's "display not initialized" placeholder, a build masked by `tee`
  reporting exit 0, and a grep that "passed" against a file that was never
  extracted. **Twelve of the eighteen bugs** found building the ISO were the
  *check* being wrong, not the code.
- **ImageMagick** silently writes greyscale when an operation drops colour, and
  `-alpha shape` on an image with no alpha produces garbage. Verify channels and
  open the file.
- **Chromium clamps `--window-size` to 500px minimum.** A "400px" render is
  really 500px cropped — load the page in an iframe of the exact width instead.
- On a clean install, **the module that reports the failure is almost never the
  module at fault.** Read the per-module logs, not the summary card.
